Lean In Circle Recommendation API
A small, explainable REST API that recommends relevant Lean In Circles to a member based on their stated topic interests and Circle activity. Built as a lightweight take-home project with FastAPI, SQLite, and a deterministic Python ranking algorithm.

Requirements
- Python 3.10+
- The five supplied JSON files in data
- The SQLite database to serve light weight relational database
- No separate database server required

Quick start (Windows PowerShell)

1. Create and activate a virtual environment
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1

2. Install dependencies
python -m pip install -r requirements.txt

3. Import the JSON data into SQLite
python scripts/ingestion.py

4. Start the server
python -m uvicorn main:app --reload

API
GET /api/users/{user_id}/recommendations
Returns a ranked list of Circles that the user could join, with short member-facing explanations. The response is JSON (application/json).

| Parameter | Location | Type | Default | Description |
| --- | --- | --- | --- | --- |
| `user_id` | Path | Integer | Required | ID of a member in the database |
| `limit` | Query | Integer | `5` | Number of results requested, from 1 to 20 |

Strategy - "Based on Your interest" if user has interest otherwise "Cold Start"

Common responses:
- 200 OK: valid request (the recommendations array can be empty if no eligible Circles are found).
- 404 Not Found: the requested user does not exist.
- 422 Unprocessable Entity: invalid user_id or limit (e.g., /users/{user_id}/... instead of a numeric ID).
- 503 Service Unavailable: the SQLite database file is missing; run ingestion first.

Database
ingestion.py creates seven tables:

| Table | Purpose |
| --- | --- |
| `users` | Member profile fields |
| `circles` | Circle metadata, capacity and activity aggregates |
| `memberships` | User-to-Circle relationships |
| `user_interests` | Stated member topic interests |
| `circle_tags` | Tags assigned to Circles |
| `topics` | Seeded topic records |
| `activity` | Seeded activity records |

Foreign keys connect memberships and interest/tag rows to their parent entities. Indexes support lookups on Circle topics, availability, memberships, tags and interests. The topics and activity imports preserve source records in raw_json; the recommendation engine currently scores using the Circle-level activity aggregates.
